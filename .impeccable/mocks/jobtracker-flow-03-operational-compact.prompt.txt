Use case: ui-mockup
Asset type: high-fidelity north-star composition board for a production web app flow
Primary request: Design option 3 for JobTracker, internally called “Operational Compact”. Show the entire desktop job-application management flow in one wide 16:9 product-design presentation board.
Structure and scale relationships: A large main dashboard screen occupies roughly two-thirds of the canvas. Use a very slim left rail with only the JobTracker mark, the active destination “Candidature”, and account/logout at the bottom. Use a compact work header with “Le tue opportunità, in ordine.”, one coral “Nuova candidatura” action, search, visible filters, and a clearly visible “Ritirate” archive/filter. Four dense equal kanban lanes use the remaining height. Show one card with its accessible overflow/status menu open to demonstrate that changing status does not depend on drag and drop. On the right, two smaller but legible UI screens are stacked: the “Nuova candidatura” dialog with essential fields first and optional fields grouped below, and the separate “Dettaglio candidatura” edit page with status control, save action, delete danger zone, back navigation, and success feedback. Include one small empty-search example containing a small friendly robot mascot placeholder; this only demonstrates placement and is not a mascot redesign.
Main board content: lanes “Candidature”, “Colloqui”, “Offerte”, “Rifiutate”; fictional Italian job cards with company, role, date, city, status text, and visible accessible status controls. The open card menu contains clear actions to move the application between statuses and to archive it as “Ritirata”. “Ritirate” is an archive/filter, not a fifth main lane. Use neutral fictional company names such as “Nordica Labs”, “Studio Ginkgo”, “Orbita”, “Faro Digitale”; do not use real brands or logos.
Visual system: “Il Compagno di Ricerca”. Operate-mode UI. Manrope-like geometric sans. Deep blue-black Night surfaces (#10161e, #0d131a, #17202a), lunar text, cool fine borders, coral primary action (#ff5146), amber/violet/green/rose semantic status signals. Surfaces nearly flat; spacing and 1px borders create structure. Shadows only on dialog, open menu, active drag, or genuinely elevated elements. Medium 12px corners, restrained density, high contrast.
Composition character for this option: dense, direct, operational. Smaller header footprint, more applications visible, stronger scan lines, compact filters, and an obvious non-drag status workflow. The interface should still breathe enough to remain readable and accessible.
Exact important Italian text only: “JobTracker”, “Candidature”, “Le tue opportunità, in ordine.”, “Nuova candidatura”, “Cerca azienda o ruolo”, “Filtri”, “Candidature”, “Colloqui”, “Offerte”, “Rifiutate”, “Ritirate”, “Sposta in Colloqui”, “Sposta in Offerte”, “Segna come Rifiutata”, “Archivia come Ritirata”, “Dettaglio candidatura”, “Salva modifiche”, “Esci”.
Constraints: designed web UI, not a poster or device mockup; no invented statistics, settings, customers, claims, prices, charts, testimonials, calendar, documents, reminders, analytics, or future features. The populated dashboard contains no mascot. Use recognizable standard controls and accessible hierarchy. The small robot is a positional placeholder only.
Avoid: neon, gaming aesthetic, glassmorphism, excessive gradients, bento marketing cards, generic SaaS analytics, huge empty hero, decorative blobs, photorealism, illegible tiny text, watermark.
