Use case: ui-mockup
Asset type: high-fidelity north-star composition board for a production web app flow
Primary request: Design option 2 for JobTracker, internally called “Focus-First Workflow”. Show the entire desktop job-application management flow in one wide 16:9 product-design presentation board.
Structure and scale relationships: A large main dashboard screen occupies roughly two-thirds of the canvas. Use a compact top navigation rather than a full sidebar: JobTracker brand, only the current destination “Candidature”, account control and logout. Below it, a calm page header with the phrase “Le tue opportunità, in ordine.”, one coral “Nuova candidatura” action, search, and a clearly visible “Ritirate” archive/filter. Add a restrained horizontal status selector directly above the board, then four equal kanban lanes. On the right, two smaller but legible UI screens are stacked: the “Nuova candidatura” dialog with essential fields first and optional fields grouped below, and the separate “Dettaglio candidatura” edit page with status control, save action, delete danger zone, back navigation, and success feedback. Include one small empty-search example containing a small friendly robot mascot placeholder; this only demonstrates placement and is not a mascot redesign.
Main board content: lanes “Candidature”, “Colloqui”, “Offerte”, “Rifiutate”; fictional Italian job cards with company, role, date, city, status text, and a visible accessible status menu/handle. “Ritirate” is an archive/filter, not a fifth main lane. Use neutral fictional company names such as “Nordica Labs”, “Studio Ginkgo”, “Orbita”, “Faro Digitale”; do not use real brands or logos.
Visual system: “Il Compagno di Ricerca”. Operate-mode UI. Manrope-like geometric sans. Deep blue-black Night surfaces (#10161e, #0d131a, #17202a), lunar text, cool fine borders, coral primary action (#ff5146), amber/violet/green/rose semantic status signals. Surfaces nearly flat; spacing and 1px borders create structure. Shadows only on dialog, active drag, or genuinely elevated elements. Medium 12px corners, restrained density, high contrast.
Composition character for this option: focused and progressive. The page title, search, archive and status selector form a clear task funnel before the board. More breathing room than option 1, with a clean top bar and no invented navigation destinations.
Exact important Italian text only: “JobTracker”, “Candidature”, “Le tue opportunità, in ordine.”, “Nuova candidatura”, “Cerca azienda o ruolo”, “Candidature”, “Colloqui”, “Offerte”, “Rifiutate”, “Ritirate”, “Dettaglio candidatura”, “Salva modifiche”, “Esci”.
Constraints: designed web UI, not a poster or device mockup; no invented statistics, settings, customers, claims, prices, charts, testimonials, calendar, documents, reminders, analytics, or future features. The populated dashboard contains no mascot. Use recognizable standard controls and accessible hierarchy. The small robot is a positional placeholder only.
Avoid: neon, gaming aesthetic, glassmorphism, excessive gradients, bento marketing cards, generic SaaS analytics, huge empty hero, decorative blobs, photorealism, illegible tiny text, watermark.
